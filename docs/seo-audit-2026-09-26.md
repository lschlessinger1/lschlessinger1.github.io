## Measured image result

A fresh Chromium context at 390 × 844 loaded 4,701,058 bytes of image resources from the previous live homepage before any scrolling. The updated local build loaded 181,920 bytes under the same viewport and observation window: **96.1% less initial image transfer**. These are browser resource-transfer observations, including response overhead, not field Core Web Vitals or a promise about search ranking. The comparison uses production before and localhost after; image bytes are the relevant measure, not their latency.

The new rating preview is 9,572 bytes and the image-quilting preview is 64,674 bytes. Both preserve the previously approved crop. Fresh contexts at 390px and 1440px showed no horizontal overflow or initial layout shift. Checked both image dialogs, Escape dismissal, and image decoding. Full originals remain linked for enlargement.
